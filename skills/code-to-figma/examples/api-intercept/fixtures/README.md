# fixtures

Put API responses fetched from the backend here (`me.json`, `orders.json`…). How to fetch them is described at the top of `../scenarios.cjs`.

- Use a demo account or test environment data. Don't put real personal data here, and don't commit it
- One file per API, with file names that match `load()` in `scenarios.cjs`
- When the backend changes its response format, fetch again. Don't add fields by hand, or the screens will show data the product never shows
